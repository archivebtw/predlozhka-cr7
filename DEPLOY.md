# Как безопасно загрузить модульное обновление

1. Скачайте резервную копию текущего `config.js` из GitHub.
2. Распакуйте архив.
3. Скопируйте текущий `config.js` в корень папки рядом с `index.html`.
4. В GitHub удалите старые `index.html` и `admin.html` либо замените их новыми.
5. Загрузите целиком папку `assets`.
6. Загрузите новые `index.html`, `admin.html` и `README.md`.
7. **Не заменяйте рабочий `config.js`.**
8. Папку `supabase` можно загрузить как резервную копию, но повторно запускать SQL не требуется.
9. Дождитесь зелёной галочки в `Actions`.
10. Откройте сайт и нажмите `Ctrl + F5`.

После проверки следующим этапом лучше отдельно доработать `twitch-theme.css` и мобильную версию, не трогая Supabase-логику.

## Автоматическая синхронизация Steam

1. Создай длинный случайный секрет и добавь его в Secrets Edge Function под именем `CRON_SECRET`.
2. Повторно задеплой `supabase/functions/steam-game`.
3. Открой `supabase/scheduled_steam_sync.sql` и замени Project URL, anon key и тот же `CRON_SECRET`.
4. Выполни SQL один раз в Supabase SQL Editor.
5. Проверь появление задания `steam-game-auto-sync` в `cron.job`.

Задание запускается каждые 6 часов. Предстоящие игры и игры без даты обновляются не чаще раза в 6 часов, вышедшие — не чаще раза в неделю. За один запуск обрабатывается до 18 игр, по три параллельно. Значения кооператива с источником `manual_admin` не перезаписываются.
