# Развёртывание ПРЕДЛОЖКА141

Этот документ описывает безопасное обновление рабочего сайта:

- репозиторий: `archivebtw/predlozhka-cr7`;
- основная ветка: `main`;
- сайт: `https://archivebtw.github.io/predlozhka-cr7/`;
- Supabase project ref: `ncqqilfkgdvnkgsiheok`;
- обновление предложки: PR `#80`.

## Что добавляет обновление

- отправку Steam-игр зрителями;
- поиск дубликатов по Steam App ID;
- поддержку уже существующей заявки;
- очередь модерации;
- отдельный публичный рейтинг;
- один голос зрителя за каждую игру;
- комментарии и их модерацию;
- статусы «выбрана», «пройдена» и «архив».

## Важный порядок действий

Сначала подготовь Supabase, затем объединяй frontend с `main`.

Так посетители не увидят интерфейс, который ещё не может обратиться к новым таблицам или обновлённой Edge Function.

```text
Резервная проверка
        ↓
SQL-миграция Supabase
        ↓
Anonymous Sign-Ins
        ↓
Edge Function steam-game
        ↓
Merge PR в main
        ↓
GitHub Pages
        ↓
Полный smoke-тест
```

## Шаг 1. Примени SQL-миграцию предложки

### 1.1. Открой файл миграции

В PR или репозитории открой:

`supabase/game_suggestions.sql`

Скопируй файл целиком, от первой до последней строки.

### 1.2. Запусти миграцию

В Supabase Dashboard:

1. выбери рабочий проект;
2. открой `SQL Editor`;
3. нажми `New query`;
4. вставь содержимое `supabase/game_suggestions.sql`;
5. нажми `Run`;
6. дождись успешного выполнения без красной ошибки.

Миграция создаёт:

- `game_suggestions`;
- `suggestion_supports`;
- `suggestion_votes`;
- `suggestion_comments`;
- индексы;
- RLS-политики;
- RPC-функции для зрителей и администратора;
- Realtime-публикации.

Миграция не удаляет существующий каталог `games`.

### 1.3. Проверь результат

В `Table Editor` должны появиться четыре новые таблицы:

```text
game_suggestions
suggestion_supports
suggestion_votes
suggestion_comments
```

Если таблицы появились, SQL-часть готова.

### 1.4. Повторный запуск

`game_suggestions.sql` рассчитан на повторный запуск при обновлении функций и политик.

Не создавай таблицы вручную и не вырезай отдельные блоки из файла.

## Шаг 2. Включи Anonymous Sign-Ins

Зрителю не нужно вводить email или пароль. При первом голосе, комментарии или предложении Supabase создаёт анонимного пользователя на его устройстве.

В Supabase Dashboard:

1. открой `Authentication`;
2. перейди в настройки провайдеров;
3. найди `Anonymous Sign-Ins`;
4. включи разрешение анонимных входов;
5. сохрани настройку.

Проверка:

- переключатель Anonymous Sign-Ins включён;
- публичный anon/publishable key в `config.js` не изменялся;
- существующий вход администратора по email и паролю продолжает работать.

Важно: анонимный пользователь использует Postgres-роль `authenticated`. Ограничения голосов, заявок и комментариев обеспечиваются RPC и уникальными ограничениями базы.

## Типовые ошибки

### «Система предложений ещё не подключена к базе»

Причина: не выполнен `supabase/game_suggestions.sql` или PostgREST ещё не обновил schema cache.

Что делать:

1. выполни SQL-файл целиком;
2. проверь наличие четырёх таблиц;
3. подожди несколько секунд;
4. обнови сайт через `Ctrl + F5`.

### «Анонимные действия пока выключены»

Причина: Anonymous Sign-Ins отключён.

Что делать:

1. открой настройки Authentication;
2. включи Anonymous Sign-Ins;
3. обнови сайт;
4. повтори действие в приватном окне.

### Steam-предпросмотр отвечает `401` или `403`

Причина: на сервере осталась старая версия `steam-game`, либо браузер использует старую сессию.

Что делать:

1. повторно выполни `npx supabase functions deploy steam-game`;
2. проверь время деплоя в Edge Functions;
3. очисти данные сайта или открой приватное окно;
4. повтори отправку Steam-ссылки.

### Steam-предпросмотр отвечает `500`

Что делать:

1. открой логи `steam-game`;
2. проверь доступность Steam Store API;
3. убедись, что `SUPABASE_URL` и `SUPABASE_ANON_KEY` доступны функции;
4. не удаляй существующие Secrets;
5. повтори запрос позднее, если Steam временно недоступен.

### Очередь модерации не отображается

Проверь:

- выполнен ли вход в админку;
- присутствует ли UUID пользователя в `site_admins`;
- выбран ли фильтр `На рассмотрении`;
- выполнена ли SQL-миграция;
- нет ли ошибок RLS в консоли браузера.

### После merge сайт не обновился

Проверь:

1. PR действительно объединён с `main`;
2. GitHub Actions завершён;
3. GitHub Pages использует правильный источник;
4. прошло несколько минут после deploy;
5. выполнен `Ctrl + F5`;
6. приватное окно показывает новую версию.

## Безопасный откат

Если frontend работает неправильно:

1. открой объединённый PR в GitHub;
2. нажми `Revert`;
3. создай и объедини revert PR;
4. дождись повторного GitHub Pages deploy.

SQL-таблицы можно оставить: без frontend они не мешают старой версии сайта.

Не удаляй таблицы предложки, если зрители уже успели отправить заявки, проголосовать или написать комментарии.

Если проблема только в Edge Function:

1. возьми предыдущую рабочую версию `supabase/functions/steam-game/index.ts`;
2. задеплой её командой `npx supabase functions deploy steam-game`;
3. frontend при необходимости откати отдельно.

## Дополнительные модули

Следующие разделы нужны только при первоначальной настройке соответствующих функций. Для одного обновления предложки повторять их не требуется.

### Автоматическая синхронизация Steam

1. создай длинный случайный секрет;
2. добавь его в Edge Function Secrets под именем `CRON_SECRET`;
3. задеплой `steam-game`;
4. открой `supabase/scheduled_steam_sync.sql`;
5. укажи Project URL, anon key и тот же `CRON_SECRET`;
6. выполни SQL один раз;
7. проверь задание `steam-game-auto-sync` в `cron.job`.

Задание запускается каждые 6 часов. Предстоящие игры и игры без даты обновляются не чаще раза в 6 часов, вышедшие — не чаще раза в неделю.

### Актуальные эфиры 141 GANG

1. создай приложение в Twitch Developer Console;
2. добавь `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` в Edge Function Secrets;
3. выполни:

```powershell
npx supabase functions deploy stream-status --no-verify-jwt
```

4. открой `141 GANG`;
5. проверь LIVE-статус, категорию и время начала эфира.

### Пройденные, неинтересные и избранные игры

Если модуль ещё не настраивался, один раз выполни:

`supabase/game_library_status.sql`

### Репутация игр основного каталога

Если модуль ещё не настраивался, один раз выполни:

`supabase/game_reputation.sql`

### Необязательный комментарий автора

Если миграция ещё не применялась, выполни:

`supabase/optional_author_comment.sql`
