# ПРЕДЛОЖКА141 — Bloodseeker redesign

Обновлённая модульная версия сайта предложений для стримера Глеба Орлова (Sasavot).

## Что изменено

- новый бренд **ПРЕДЛОЖКА141**;
- красно-чёрная тема, вдохновлённая Bloodseeker;
- удалены шесть боковых фотокарточек Tankzor;
- добавлен экран загрузки с плавным исчезновением;
- Twitch-ссылки переведены на `twitch.tv/sasavot`;
- публичный каталог и админ-панель оформлены в единой теме;
- Supabase, Steam Edge Function, авторизация, CRUD, Realtime, сортировка и фильтры сохранены.

## Важные файлы

- `index.html` — публичный сайт;
- `admin.html` — админ-панель;
- `config.js` — текущее подключение Supabase, не заменять чужим;
- `assets/images/bloodseeker.webp` — основной тематический ассет;
- `assets/css/public/loading.css` — экран загрузки;
- `assets/js/public/loading.js` — логика скрытия загрузчика.
