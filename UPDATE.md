# Обновление ПРЕДЛОЖКА141

Загрузи содержимое проекта в корень GitHub-репозитория с заменой файлов.

Не меняй значения внутри рабочего `config.js`.

Добавлена полноценная предложка зрителей:

- дедупликация Steam-игр по App ID и поддержка существующей заявки;
- очередь модерации со статусами и историей решений;
- отдельный публичный рейтинг с одним голосом зрителя за игру;
- один редактируемый комментарий зрителя к каждой игре;
- скрытие комментариев администратором;
- анонимные Supabase-сессии вместо небезопасной проверки только по IP.

Перед публикацией выполни `supabase/game_suggestions.sql`, включи Anonymous Sign-Ins и повторно задеплой `supabase/functions/steam-game`. Подробности находятся в `DEPLOY.md`.
